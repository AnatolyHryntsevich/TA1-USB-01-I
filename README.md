# mil-std-1553b-usb-terminal

Программа управления шиной MIL-STD-1553 (ГОСТ Р 52070-2003) через USB-интерфейс.
Предназначена для отладки и тестирования ЭВМ, работающих в сети MIL-STD-1553. Является реализацией API драйвера модуля сопряжения с шиной MIL-STD-1553 TA1-USB производства АО «Элкус» (http://www.elcus.ru/boards.php).
Отладка при разработке производилась на TA1-USB-01-I 

## Сборка и запуск проекта

Qt5, C++17, CMake 3.25, linux / windows
